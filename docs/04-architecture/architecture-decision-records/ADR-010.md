| Context | Planning chat for a zero-cost, local, professional prototype for the MDU group |
| Decision | Cloud GPU: Kaggle free (2 x T4, 32 GB) is the main cloud GPU. Google Colab free (1 x T4, 16 GB) is the backup for jobs that fit 16 GB when Kaggle's weekly quota is used up or Kaggle is unavailable. The smoke test of 1.5 confirms both |
| Rationale | Two T4s hold Qwen3.5-9B in full 16-bit (19.31 GB) and Qwen3.8-27B in 4-bit (16.56 GB). One T4 holds neither. Kaggle's GPU is available within its weekly quota. Colab's free GPU is not guaranteed |
| Replaced or rejected option | Colab free as main and Kaggle as backup (until 11 November 2026). Colab premium (rejected: costs money) |

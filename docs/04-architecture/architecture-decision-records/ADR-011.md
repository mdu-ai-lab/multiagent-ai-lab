| Context | Planning chat for a zero-cost, local, professional prototype for the MDU group |
| Decision | GPU profile model: Qwen3.5-9B in full 16-bit (fp16, because the T4 has no bf16) split over Kaggle's 2 x T4. Qwen3.8-27B in 4-bit tested on Kaggle 2 x T4 and used only if it runs well. On the Colab backup (1 x T4): Qwen3.5-9B in 8-bit. The exact files are chosen and pinned in 1.5 |
| Rationale | The full Qwen3.5-9B is 19.31 GB and does not fit one 16 GB T4. The full Qwen3.8-27B is 55.56 GB, so 2 x T4 needs 4-bit |
| Replaced or rejected option | Qwen3.5-9B at higher precision on a Colab T4 (does not fit). 27B on paid Colab |
